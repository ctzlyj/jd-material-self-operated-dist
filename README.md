## 安装与升级

- 管理员在 https://material-auth.space.jd.com/ 为本人 ERP 开通自营 Skill；插件、POP和其他产品资格不通用。
- 本人登录 HiOffice 和自营后台，保持京东网络可用。不要借用同事身份或提供密码、Cookie、票据。
- 获取完整仓库，不要只下载 `SKILL.md`。Codex先阅读 `jd-material-self-operated/SKILL.md`、`references/first-use.md` 和 `references/protected-service.md`。
- 安装依赖后由 Codex 执行 `python tools/install.py`；安装器校验 `DISTRIBUTION.json`，同时安装主Skill及配套传输组件。
- 旧受保护安装原位升级，保留本地状态；冲突暂存于 `.merge-candidates`，拒绝覆盖未保护的维护人私有安装。任务在途时不升级，不清空缓存或重建账本。
- 仅安装或升级不授权恢复暂停任务。缺少本人登录或ERP资格时说明实际阶段，不因401、429反复要求输入Key。

## 本版变化与边界

客户端和选定服务端核心为 `2026.09.17.1`。新增Gemini两款可选路由，排除中间思考图；白底、场景和卖点图仍按原技术规则输出，透明图本地处理。Pro默认2、Flash默认1是保守配置，不是最大稳定并发或生产提速结论；旧GPT默认4保持。

修复Key仅保存在单次子进程及只读命令误索Key的问题：复用进程/Windows当前用户环境和系统加密凭据，配置锁避免并发重复弹框。Windows DPAPI已用模拟值跨进程验证；同事电脑及其他OS密钥库未逐机验收。

旧自营核心及POP核心保持，不能伪造版本或失败后本地回退。只交付受保护客户端，不交付私有核心、维护人备份、授权名单、凭据或生产账本。详见 `验收说明.md` 和 `DELIVERY_VERIFICATION.json`。
