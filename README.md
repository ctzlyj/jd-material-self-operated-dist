新用户和已安装旧版的同事均可使用：

```text
请从 https://github.com/ctzlyj/jd-material-self-operated-dist 获取并核验2026.09.18.2或更高的已验收正式受保护自营Skill。先检查我是否已安装、安装来源、本地修改和真实运行进程/锁，使用原安装器非破坏安装或升级完整Skill及配套组件，不覆盖私有安装，不打断在途任务。保留原计划、完整SKU、字段排除、有效图片、URL、未知写入、失败回执和系统加密凭据。安装新版后读取SKILL.md及自动更新、自主排障说明，确认后续兼容正式版会在正常使用时自动检查升级，无须每次提醒。旧版先接入这一次即可。遇到环境、接口适配或本地代码问题，由你优先查O2和随包能力，复现后补回归、最小修复并验证，不因Skill没封装就反复让我找维护人。冲突在本机保留并三方合并，不强制覆盖、不绕过ERP授权或私有核心、不盲重传未知写入。只用受控后台浏览器，不操作工作标签页；只读、安装和升级不索模型Key，确实缺少时才在需要生成时本机遮罩配置，不在聊天索要或回显。本次只安装升级并验证，不自动恢复维护、扫描商品、重试历史失败、部署服务或修改权限名单。最后告诉我实际安装版本、自动更新状态、是否有未解决的本地冲突。
```

安装完成后，另行明确维护范围即可。自动维护只处理本人有权范围的短标题、卖点、场景图、卖点图、白底图和透明图，排除主图视频；不走人工表格。普通最终失败/驳回整SPU跳过并交付全部SKU、具体原因、证据和SHA；未知写入先精确只读核销，不盲重传。维护授权不包含自动隔离新未知项或重试历史失败。

## 本版变化

- 启动前自动更新：每6小时最多检查一次原仓库正式Release，验证成功CI、精确commit、清单SHA及显式兼容来源。下载不可用保留旧可用版；不常驻、不装定时任务。
- 在途任务不热替换，安装失败在业务启动前回滚。本地修改不覆盖，冲突由当前Codex合并并回归；跨核心、依赖、共享浏览器或账本格式变更先评估兼容，不盲装。
- 自主排障：Codex先找现有接口/工具，补失败回归后修复本地执行层，不以“当前版本不支持”为由反复等维护人。真实ERP权限、私有核心及未知写入门禁仍保留。
- 多未知上传隔离：在逐SPU明确授权后追加证据链，冻结该SPU全部当前未知图片，保留旧证据、完整SKU和有效素材；不重传、不自动隔离后续目标、不计完成。
- 保留Gemini可选路由、本地透明图、Key安全复用及原频控。Pro默认并发2、Flash1，旧GPT4；不宣称最大稳定并发或提速已证明。

客户端为`2026.09.18.2`，固定兼容的既有服务端核心`2026.09.17.1`；本次不需要部署授权服务。旧用户需先接入一次含更新器的新版，不能只凭发布就让没有更新器的旧安装自动升级。私有维护人安装不自动更新。

## 安装与边界

- 管理员需为真实本人ERP开通自营Skill资格；插件、POP和其他产品不通用。本人登录HiOffice、自营后台并保持京东网络可用，不借用身份或提供密码/Cookie。
- 获取完整仓库，不要只下载`SKILL.md`。Codex阅读`jd-material-self-operated/SKILL.md`和对应references，准备依赖后执行`python tools/install.py`。
- 原安装器校验分发清单，保留本地独有文件和状态，将冲突暂存；禁止覆盖维护人私有安装。升级不解除暂停、不清Key或账本、不扩大维护范围。
- 自动更新控制由Codex执行`python scripts/auto_update.py status|check|enable|disable|recover`，各操作及停止条件见`references/auto-update.md`。未使用时不检查，离线/匿名限流时不索要GitHub Token。
- 只分享受保护分发，不分享私有源码、维护人备份、数据库、凭据或生产账本。详见`验收说明.md`和`DELIVERY_VERIFICATION.json`；同事设备尚未逐机验收。
