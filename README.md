## 一次性准备

- 管理员先在 [授权管理页面](https://material-auth.space.jd.com) 为同事真实 ERP 开通“自营 Skill”；POP、插件资格不通用。
- 本人登录 HiOffice 和自营业务后台，保持京东网络可用。身份必须一致，不借用他人账号。
- Codex 检查并准备 Python 3.12+、Node.js 22.15+、依赖和 Browser Bridge。必要的本人登录仍由本人完成。
- 模型 Key 由安全环境或本地隐藏输入提供，不提交到聊天、文件或 GitHub。不要把别人的 Key 放到这个仓库。

## Codex 安装入口

完整获取仓库，不要只下载 `SKILL.md`。先读 `jd-material-self-operated/SKILL.md`、`references/protected-service.md` 和 `references/first-use.md`。

在本仓库根目录，安装所需 Python 依赖后执行 `python tools/install.py`。安装器先核验 `DISTRIBUTION.json`，一起安装主 Skill 与 `webcli-browser-runtime`；遇到旧未保护版安装或本地修改冲突时保留原文件，不能强行覆盖。安装后可直接读取安装位置的 Skill 执行，不要求用户自己掌握命令。

首次直接维护入口为 `scripts/self_operated_cli.py maintain-self-operated --confirm GENERATE_UPLOAD_BIND_AND_VERIFY --image-transport direct-http --short-title-transport osw --defer-readback`，由 Codex 在已授权范围内调用。已有任务必须沿原账本和目录恢复，不能因换了安装来源重新生成、丢掉排除清单或重放未知写入。升级本身不授权恢复已暂停任务。详情见 [首次使用说明](jd-material-self-operated/references/first-use.md)。

旧受保护版升级前先等待任务安全停止；使用原安装器升级同一目录，不卸载、不清缓存。未改文件可同步，本地独有文件保留，冲突进入 `.merge-candidates` 待合并。未经核验不得直接覆盖维护人私有安装。

## 授权与公开边界

任何人可以下载、复制或转发本客户端，但只有获准的真实 ERP 能调用服务端受保护核心。删除客户端检查不能取得仓库中不存在的私有算法。撤销授权影响后续受保护服务调用，不会收回已下载文件、生成图片或既有结果，也不限制他人独立重新实现业务流程。
