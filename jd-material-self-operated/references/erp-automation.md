# Internal model limits

Do not invent a per-run image-request cap. Daily allowance is not verified remaining balance.
Keep four image requests concurrent at most, at most one start per second and the existing bounded retries.
Pause on actual quota exhaustion or authentication failure. These are preserved client settings, not a newly measured platform maximum.
Self-operated procurement uses authenticated ERP permissions, never a personal shop name. Only upload image files; deliver workbooks for the user's manual imports.
